# Trace interface direction

Trace is an investigation workbench: cases, domain leads, relationships and
source evidence. Preserve the existing graphite workspace so the recon dialog
belongs to the graph and editors rather than resembling a separate dashboard.

ENERGY 1 / RHYTHM 2 / MOTION 1.

Use the existing sans-serif for controls and reading; monospace belongs to
hostnames, hashes and machine-readable configuration. Teal identifies the next
primary action and selected workspace section. Neutral surfaces separate input
from evidence; muted text remains readable. Danger and warning colors always
have text labels. Avoid decorative icons, new assets and animation.

The repeated motif is the investigation record: domain first, provenance and
plain-language status second, evidence and an explicit decision below. A compact
collection form introduces a wider evidence ledger. Settings and assistant
configuration are secondary tasks, each reached through named buttons within the
existing Recon & MCP dialog. This arrangement gives collection and review more
space than connection plumbing. On narrow screens, all sections stack; the
header, section controls and operation feedback remain outside the scroll body.

Controls have visible borders, hover/pressed/disabled states, a contrasting
keyboard outline and targets at least 44 CSS pixels high. Long domain names,
errors and configuration wrap. Use native dialog, form, details and checkbox
semantics. Preserve Escape and return focus to the opening control.

Copy names what happens: save connection, check connection, collect domains,
review evidence, import selected candidates. Never imply that a certificate name
establishes ownership or that an assistant proposal has been verified. Dates,
counts, capabilities and connection labels come from actual saved data/results.

The case agent extends the same workbench. Conversation text is the focal point;
a compact composer keeps the selected account and sharing choice visible. Model
configuration and context previews expand only when needed. Each reply identifies
its provider and sharing state. Source references open actual case records;
proposals lead directly to the existing review inbox. Provider availability is
operational state, never a fabricated balance or plan-entitlement claim. Keep
ENERGY 1 / RHYTHM 2 / MOTION 1; new replies follow the transcript only while the
operator remains near its end, preserving intentional reading of older messages.

At short effective viewport heights, including desktop zoom, the agent switches
to full-dialog scrolling with a bounded transcript and sticky feedback. This
keeps the input and Send control reachable instead of shrinking the composer into
a narrow fixed pane. Account details and sharing previews stay expandable.
